# RGSS 地图查看器实施计划

## 目标

让 RGSS 修改器的迷你地图严格对应游戏地图的实际格子，并能完整查看、缩放、定位和检查事件。地图数据取自运行中的游戏对象，所有事件和玩家标记与地图格分开绘制。

## 交互与显示约定

- 地图宽、高直接使用当前 RGSS 地图的 `width` 和 `height`；每个游戏坐标对应一个独立格子，不做抽样合并。
- 默认缩放为「完整适配」：整张地图宽高都落在弹窗可视区域内。缩放滑块的最小值始终对应完整适配，增大时允许拖动平移查看细节；隐藏横纵滚动条，滚轮和触控板仍可滚动。
- 地图地形、格线和事件类别颜色在日间/夜间保持一致；夜间模式只改变周围界面层。不可通行格用深灰、可通行格用灰绿；格线在浅色/深色地形上使用对应的低对比度颜色以保持清楚。事件编号统一使用圆角方块，通过蓝、紫、橙、红区分普通事件、传送、可移动/敌人、宝箱/道具事件；玩家使用主色绿方块。主标记和编号都按格子尺寸同比例缩放，不设固定像素上限；同格多个事件不改变编号样式，点击事件解释器后查看事件列表。图例色块与主标记一一对应，不混用多种事件形状；地图外沿仅保留细线作边框，不作为图例类别。
- 图例包含 7 类：可通行、不可通行、事件、玩家、敌人/可移动事件、宝箱/道具变化事件、传送点。点击格子后增加独立的浅绿底与绿色边框作为临时选中态。
- 「可能的隐藏路径」不是 RGSS 事件的标准标记，当前没有可靠数据来源，因此不做猜测标注；临时选中态也不计入 7 个固定图例类别。
- 轻点任意格只选中并高亮，坐标显示在左侧操作卡；点击地图视口内地图以外的空白区域可取消选中，清除坐标并禁用操作按钮。“传送”和“事件解释器”按钮位于左卡，缩放滑块位于右卡。按下移动超过 6px 视为拖动；按住超过 500ms 后释放不触发选格。没有事件的格子仍可传送；传送后保持小地图打开并刷新地图；选中后点事件解释器，单事件直接显示详情，多事件才显示事件列表，无事件时提示没有事件。
- 事件位置在打开小地图时读取一次，不做实时轮询；关闭并重新打开时读取最新位置，避免持续读取地图数据影响游戏帧率。
- 事件列表、事件页与指令详情以叠层弹窗显示在地图上，关闭上层后回到地图。事件类型根据页面指令识别：201 传送，202/205/301 可移动或敌对事件，125–128 金钱/物品/武器/护甲变化。

## 实施阶段

1. **已完成：修复地图数据契约**：移除会缩减格数的抽样；行数据仅表达可通行/不可通行，玩家与事件坐标单独传输；补充可识别的传送事件标记。
2. **已完成：重做地图绘制与缩放**：默认按地图宽高适配弹窗可用宽高；增加适合手指拖动的卡片式滑块；隐藏滚动条并支持直接拖图；颜色、格线和标记对齐修改器面板主题。
3. **已完成：增加选格与地图操作栏**：短按选格并高亮，拖动平移不误触；左卡显示坐标与传送/事件解释器按钮，右卡控制缩放；任何格子可传送；事件列表、事件页和指令详情叠加在地图上，并支持同格多事件。
4. **已完成代码收尾**：补齐英文/日文界面文案、README 与发布说明。

游戏内人工验收尚未执行；本次没有运行构建或测试。实际游戏中仍需按下方清单检查边界、不同地图尺寸、缩放和事件交互。

## 验收要点

- `width × height` 个逻辑格都可对应到原始坐标，地图边界没有漏格或合并格。
- 小地图初开时整张图全部可见；拖动滑块可连续放大/缩小，回到最小值恢复完整适配。
- 地形色、事件编号、玩家位置与各类事件颜色标记互不覆盖数据，标记不会改变格子的通行颜色。
- 轻点地图格后只选中并在左卡显示坐标；左卡操作按钮、右卡缩放滑块在窄屏下仍清晰可用；移动超过 6px 或按住超过 500ms 后释放不会触发选格。
- 选中格有独立高亮；事件标记仍显示在高亮层上方。
- 事件列表、事件页和事件解释器详情叠加在地图上，关闭上层后能回到地图。
- 空格可传送；选中事件格后点事件解释器可查看事件；多事件格会列出全部事件；没有事件时有明确提示。
- VX/VX Ace/XP 的尺寸和边界正确，适用的 Pokémon Essentials 地图仍可显示。
